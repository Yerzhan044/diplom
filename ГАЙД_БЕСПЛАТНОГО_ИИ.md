## 🚀 Быстрый старт (Выберите один)

### Вариант 1: Ollama (Локально, Полностью бесплатно) ✅

**Шаг 1**: Установите Ollama
```bash
# Скачайте с: https://ollama.ai
# Или установите через пакет-менеджер:
brew install ollama          # macOS
sudo apt install ollama      # Linux (Debian/Ubuntu)
winget install Ollama        # Windows
```

**Шаг 2**: Запустите Ollama
```bash
ollama serve
# Ollama теперь работает на: http://localhost:11434
```

**Шаг 3**: Загрузите модель (один раз)
```bash
# В другом терминале:
ollama pull mistral
# Скачивает: ~4.1GB (модель mistral)
# Или: ollama pull neural-chat (меньше, быстрее)
```

**Шаг 4**: Запустите систему обнаружения мошенничества
```bash
python3 -m train.train_model
uvicorn app.main:app --reload
```

**Готово!** Система автоматически обнаружит Ollama и будет её использовать. Ключ API не требуется.

**Проверьте статус**:
```bash
curl http://localhost:8000/health | jq .llm_source
# Ответ: "ollama (local, free)"
```

### Вариант 2: Groq (Облако-базированный, бесплатный тариф) ✅

**Шаг 1**: Получите бесплатный API ключ

**Шаг 2**: Добавьте в .env

**Шаг 3**: Установите SDK Groq

**Шаг 4**: Запустите систему
```bash
python3 -m train.train_model
uvicorn app.main:app --reload
```

**Готово!** Система автоматически обнаружит Groq и будет её использовать.

**Проверьте статус**:

curl http://localhost:8000/health | jq .llm_source
# Ответ: "groq (free tier)"

**Лимиты** (Бесплатный тариф):

- ✅ Достаточно для ~500 транзакций в день

## 🔄 Как работает приоритет

Система автоматически пробует (по порядку):

```
1. Ollama (если запущен локально) ← Пробует первым
2. Groq (если GROQ_API_KEY установлен)
3. Claude API (если ANTHROPIC_API_KEY установлен)
4. Резервный вариант (на основе правил, без ИИ)
```

**Пример**:
```
Если Ollama запущен → использует Ollama (бесплатно)
Если Ollama не найден → пробует Groq (бесплатно)
Если нет ключа Groq → пробует Claude (платно)
Если ничего нет → работает нормально, просто без объяснений ИИ
```

## 📊 Сравнение производительности

### Задержка (на одну транзакцию)

| Провайдер | Задержка | Стоимость/1K | Заметки |
|-----------|----------|----------|--------|
| Ollama | 200-500ms | Бесплатно | Зависит от железа |
| Groq | 100-200ms | Бесплатно | Очень стабильно |
| Claude | 100-150ms | $3 | Самый быстрый, премиум |

### Качество

Все три создают объяснения на естественном языке:

**Одинаковый входной**: Решение REVIEW, высокий риск страны, ночная транзакция

**Ollama выход**:
```
"Эта транзакция требует проверки из-за высокого риска
страны и ночной активности. Сумма в пределах нормы,
но время подозрительно."
```

**Groq выход**:
```
"Транзакция требует проверки: обнаружена высокий риск
страны и ночная покупка. Рекомендуется дополнительная
верификация."
```

**Claude выход**:
```
"Эта транзакция требует ручной проверки из-за высокого
риска страны (Россия) и ночной активности (02:45 UTC).
Однако сумма в пределах типичного диапазона и паттерны
скорости нормальны."
```

## 💡 Продвинуто: Пользовательский ИИ

Хотите использовать другого провайдера? Добавьте в `app/llm_free.py`:

```python
class CustomLLMExplainer:
    def __init__(self):
        self.api_key = os.getenv("CUSTOM_API_KEY")
        
    def generate_explanation(self, ...):
        # Ваша пользовательская реализация
        pass
```

Затем обновите инициализацию в `app/main.py`:
```python
custom = CustomLLMExplainer()
if custom.available:
    llm_explainer = custom
```
