## 🎯 Как добавить в диплом

### Вариант 1: Копирование диаграмм в Word/Google Docs

1. **Открыть Mermaid Live Editor**:
   - Перейти на https://mermaid.live/

2. **Для каждой диаграммы**:
   - Открыть файл из `docs/diagrams/`
   - Скопировать содержимое
   - Вставить в mermaid.live
   - Нажать Export → PNG (или SVG)
   - Вставить изображение в диплом

### Вариант 2: Прямое внедрение в Markdown/Google Docs

````markdown
```mermaid
[содержимое файла]
```
````

````

Поддерживается в:
- Google Docs (с плагином)
- GitHub/GitLab
- Markdown редакторах
- VS Code

### Вариант 3: Скопировать текст из DIAGRAMS_GUIDE.md

Документ `docs/DIAGRAMS_GUIDE.md` содержит все диаграммы с объяснениями — можно копировать целые разделы прямо в диплом.
````

## 💡 Советы по использованию

### 1. Форматирование изображений в Word

- Размер: 100-150% ширины страницы
- Выравнивание: центр
- Подпись: "Рис. X.Y. [Описание]"
- Ссылка в тексте: "как показано на Рис. X.Y"

### 2. Качество экспорта

- Используйте **PNG** для печати (300 DPI)
- Используйте **SVG** для интерактивных документов
- Для веб-версии: любой формат

### 3. Описание диаграмм

Для каждой диаграммы в дипломе добавьте:

- Заголовок
- Описание (2-3 предложения)
- Легенда (если нужна)
- Ссылка на модуль в коде

## 📝 Пример текста для дипломной работы

### Архитектура системы (из 02_architecture.md)

Система состоит из пяти основных компонентов:

1. **API Layer (FastAPI)**
   - Endpoints: GET /health, POST /score, POST /upload-csv, GET /, GET /security-metrics
   - Принимает JSON транзакции
   - Возвращает решение и объяснение

2. **Core Processing Pipeline**
   - Feature Engineering: извлечение 17 признаков
   - ML Models: ансамбль из 3 supervised моделей
   - Rule Engine: 3 набора правил
   - XAI Module: генерация SHAP объяснений
   - Decision Logic: агрегация и финальное решение

3. **ML Models (4 модели)**
   - RandomForest (300 trees)
   - ExtraTrees (400 trees)
   - GradientBoosting (250 rounds)
   - Isolation Forest (anomaly detection)

4. **Storage**
   - fraud_model.joblib: VotingClassifier
   - anomaly_model.joblib: IsolationForest
   - predictions.jsonl: все решения
   - suspicious_transactions.jsonl: детали REVIEW/DECLINE

5. **Frontend**
   - Web dashboard для загрузки CSV
   - Таблица результатов
   - Статистика и метрики
