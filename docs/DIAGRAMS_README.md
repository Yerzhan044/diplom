## 🚀 Быстрый старт

### Вариант 1: Просмотр всех диаграмм

```bash
# Откройте в браузере
open docs/diagrams_viewer.html
# или
firefox docs/diagrams_viewer.html
```

### Вариант 2: Редактирование на mermaid.live

```
1. Откройте https://mermaid.live/
2. Скопируйте содержимое любого файла из docs/diagrams/
3. Вставьте в левую панель
4. Отредактируйте при необходимости
5. Экспортируйте PNG/SVG
```

### Вариант 3: Копирование в диплом

```
1. Выберите нужную диаграмму из docs/diagrams/
2. Экспортируйте в PNG на mermaid.live
3. Вставьте в diploma_unique_v3.docx
4. Добавьте подпись: "Рис. X.Y. [Название]"
```

## 💡 Примеры использования

### Для PowerPoint / Гугл Слайдов

```
1. Экспортируйте диаграмму как PNG
2. Вставьте как изображение
3. Добавьте текст рядом с объяснением
```

### Для Word документа

```
1. Откройте диаграмму на mermaid.live
2. Нажмите Export → Download as PNG
3. Вставьте в Word: Insert → Pictures
4. Добавьте подпись через Insert → Caption
```

## ✅ Проверка качества

Перед добавлением в диплом убедитесь:
- [ ] Диаграмма отображается на mermaid.live
- [ ] Все компоненты четко видны
- [ ] Нет перекрытий текста
- [ ] Размер подходит для печати
- [ ] Разрешение достаточное (для печати ≥300 DPI)

## 🎯 Ключевые параметры системы

Эти значения должны быть отражены в диаграммах:

| Параметр | Значение |
|----------|----------|
| APPROVE порог | < 0.65 |
| REVIEW порог | 0.65 - 0.85 |
| DECLINE порог | ≥ 0.85 |
| Supervised вес | 50% |
| Anomaly вес | 20% |
| Rules вес | 30% |
| RandomForest trees | 300 |
| ExtraTrees trees | 400 |
| GradientBoosting rounds | 250 |
| Isolation Forest contamination | 10% |
