⚖️ 3. Ансамблевое голосование

Агрегация оценок

  • Supervised score = (3×RF + 3×ET + 2×GB) / 8
  • Anomaly score = Isolation Forest output ∈ [0, 1]
  • Rule score = max(velocity, geographical, behavioral)
  • Final = 0.5×supervised + 0.2×anomaly + 0.3×rules
