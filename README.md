# Real-time Credit Card Fraud Prevention

Дипломный MVP-проект по предотвращению мошеннических транзакций в реальном времени.

## Адаптация под вашу дипломную документацию

- Тема: Real-time Credit Card Fraud Prevention.
- Специальность: Network Security.
- Фокус: ансамблевые методы машинного обучения и интерпретируемость решений.

### Цель исследования

Разработать и реализовать систему обнаружения мошеннических транзакций в реальном времени на основе ансамблевых моделей машинного обучения с объяснимыми решениями.

### Объект и предмет исследования

- Объект: процесс обеспечения кибербезопасности платежных систем при обработке финансовых транзакций.
- Предмет: методы и алгоритмы машинного обучения для выявления мошеннических операций.

### Научная новизна

- Интеграция гибридного контура Rule Engine + Ensemble ML в едином real-time сервисе.
- Сочетание высокой точности ансамбля с интерпретируемостью через причины правил.
- Поддержка потокового сценария для демонстрации практической применимости.

### Практическая значимость

- Снижение финансовых потерь за счет раннего выявления подозрительных транзакций.
- Повышение безопасности платежных операций и доверия пользователей.
- Возможность поэтапного внедрения в банковскую инфраструктуру.

## Что реализовано

- Real-time API для скоринга транзакций (`/score`).
- Гибридный подход: **Rule Engine + ML probability**.
- Online-признаки на лету (velocity и отклонение от среднего чека).
- Симулятор транзакционного потока.
- Скрипт обучения ensemble-модели (soft voting) на синтетических данных.

## Стек

- Python 3.11+
- FastAPI + Uvicorn
- scikit-learn
- pandas / numpy

## ML-модель

- Используется ensemble из трех алгоритмов:
  - RandomForest
  - ExtraTrees
  - GradientBoosting
- Финальная вероятность fraud получается через soft voting.
- При обучении выводятся метрики для отчета:
  - ROC-AUC
  - PR-AUC
  - Best F1 threshold

## Быстрый старт

1. Установить зависимости:

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

2. Обучить и сохранить модель:

```bash
python3 -m train.train_model
```

3. Запустить API:

```bash
uvicorn app.main:app --reload
```

4. Открыть в браузере `http://127.0.0.1:8000/` и загрузить CSV через кнопку на главной странице.

5. Проверить поток транзакций:

```bash
python3 simulator/generate_stream.py --count 60 --rate 5
```

## CSV upload

На главной странице доступна загрузка CSV-файла с транзакциями. **Обрабатываются первые 50 строк** для быстрой демонстрации.

Минимальные обязательные колонки:

- `transaction_id`
- `card_id`
- `amount`
- `country`
- `mcc`
- `timestamp`

Дополнительно можно передавать:

- `merchant_id`
- `currency`
- `device_id`
- `ip_address`

После загрузки система покажет (для первых 50 строк):

- сводку по `APPROVE / REVIEW / DECLINE`
- средний fraud score
- таблицу результатов по каждой транзакции

### Генерация CSV в нужном формате

Если нужен готовый файл под загрузку, можно сгенерировать его командой:

```bash
python3 tools/generate_demo_csv.py --rows 50 --output demo_transactions.csv
```

После этого файл `demo_transactions.csv` можно сразу загрузить через кнопку на главной странице.

## Формат решения

API возвращает:

- `fraud_probability` — вероятность от ML.
- `rule_score` — риск от правил.
- `final_score` — итоговый риск (0..1).
- `decision`:
  - `APPROVE` — пропустить
  - `REVIEW` — отправить на ручную проверку
  - `DECLINE` — отклонить
- `reasons` — объяснения, какие правила сработали.
